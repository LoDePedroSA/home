Por ahora, las webs las estamos haciendo de manera gratuita para hacernos llegar a mas personas. Lo que incluye nuestro servicio es:

  • Crear la pagina a tu gusto (colores, logos, animaciones, etc).
  • Actualizar los contenidos cada vez que sea necesario.
  • Una base de datos de Google.
